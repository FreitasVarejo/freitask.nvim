# Domínio

O porquê deste repo mora no vault, não aqui: o repo carrega o contrato, o vault
carrega as decisões e o backlog.

- Projeto: `~/ObsidianVault/projects/workflow-ia/` — tasks em `tasks/`, decisões em
  `decisoes/`, glossário em `glossario.md`.
- A fiação na máquina (shim `freitask`, instalação da TUI, `FREITASK_REPO`) é dos
  dotfiles: `~/dotfiles/AGENTS.md`.
